# 📚 Livraria Aurora — Dashboard de Vendas

Dashboard interativo desenvolvido para análise de vendas de uma livraria fictícia.

O projeto apresenta indicadores comerciais, análises de produtos, clientes, funcionários e desempenho de vendas utilizando Python e ferramentas de análise de dados.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Streamlit

## 📊 Análises realizadas

O dashboard permite analisar:

- 💰 Faturamento total
- 💵 Lucro
- 📚 Livros mais vendidos
- 🏷️ Desempenho por categoria
- 👨‍💼 Desempenho dos funcionários
- 🌎 Análise por cidade
- 👥 Perfil de clientes
- 📈 Evolução das vendas ao longo do tempo

## 🎯 Objetivo

Demonstrar a aplicação de técnicas de análise de dados na transformação de informações comerciais em insights para tomada de decisão.

## 📌 Funcionalidades

✅ Filtros interativos  
✅ Indicadores de desempenho  
✅ Gráficos dinâmicos  
✅ Exportação de dados  
✅ Atualização automática dos indicadores
